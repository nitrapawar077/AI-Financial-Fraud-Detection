# AI Financial Fraud Detection

An AI-powered financial fraud detection system that uses machine learning to identify potentially fraudulent financial transactions.

## Project Overview

Financial fraud is a major challenge for financial institutions and digital payment systems. This project uses machine learning techniques to classify transactions as legitimate or fraudulent.

The project covers the complete machine learning workflow, including data generation, exploratory data analysis, preprocessing, model training, evaluation, and fraud prediction.

## Objectives

- Detect potentially fraudulent financial transactions.
- Generate and analyze transaction data.
- Perform exploratory data analysis.
- Preprocess and prepare data for machine learning.
- Train and compare multiple classification models.
- Evaluate model performance using suitable metrics.
- Predict whether a transaction is fraudulent or legitimate.
- Provide a foundation for real-time fraud detection using Flask API.

## Machine Learning Models

The project uses and compares the following classification algorithms:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. Gradient Boosting Classifier
